# OverCut — Changelog

## v1.1.0
**Settings & Polish**
- Settings page inside the manager window (no popup)
- Windows startup toggle — adds/removes from registry
- Dark / Light theme with instant restart apply
- Key capture widget — click field, press any key or mouse button combo
- Numpad keys correctly identified (Num0–Num9, Num+, NumEnter, etc.)
- Mouse side buttons (Mouse3–Mouse8) now capturable
- Changelog viewer accessible from Settings
- Translucent overlay background
- Auto-close overlay when focus is lost, with fade-out animation
- Custom tray icon loaded from overcut.ico
- Window and taskbar icon fixed
- Overlay header keyboard icon removed
- Search icon size fixed
- Hint pills replaced with clean plain text

## v1.0.0
**Initial Release**
- Floating shortcut overlay via global hotkey (default: Ctrl+Shift+Space)
- Category-based shortcut manager
- Live search filtering across keys, actions, and categories
- Amber highlight on matched rows
- Keyboard navigation in overlay (↑ ↓, Esc)
- Slide-in animation on overlay open, fade-out on close
- System tray with context menu and double-click to restore
- Persistent JSON data storage next to the executable
- Bundled font pipeline: Inter, JetBrains Mono, Roboto Condensed, Zalando Sans Expanded
- PyInstaller single-file exe with bundled fonts
